# Project_6
<br>
<b>Custom STM32F103C8T6 USB Type-C Development Board</b>
<br>
Designed a custom STM32F103C8T6 Development Board from scratch using KiCad, focusing on creating a compact and reliable ARM Cortex-M3 development platform powered through USB Type-C. The board includes USB Type-C power input, a 3.3 V voltage regulator, 8 MHz crystal oscillator, SWD programming interface, reset and user buttons, status LEDs, and GPIO headers for connecting external modules and sensors.
